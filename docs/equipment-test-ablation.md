# 装备固定数值断言消融记录

日期：2026-10-21。只修改检查方式，不修改装备数据，不部署游戏。

## 精简内容

- `test_item_resources.py` 从 21 项逐装备检查，精简为单机、联机各一项通用源码合法性检查。
- 删除价格、材料组合、属性值、固定 ID、图标长度、说明文案和脚本实现字符串等快照式断言。
- 联机隔离检查不再固定 0 金、视野状态、文件数量；仍检查不读取单机源码、映射来源及打包隔离。
- ID 检查不再限制在人工固定的 10001–10199 区间；保留正整数、唯一性、与官方 ID 不冲突。
- Lua 行为测试中的输入样例、打包 CRC/SHA256、路径保护及 Release 提交匹配检查保留；这些不固定真实装备平衡数值。

## 前后对比

精简前：资源测试 21 项，20 项通过，1 项因玲珑心标价 8175 与当前材料总价 8375 不同而失败。
精简后：单机、联机两项源码合法性检查均通过；不再将材料总价不等于成品标价判为源码非法。
这不表示装备数值已在游戏中正确生效，只表示配置结构和引用有效。
